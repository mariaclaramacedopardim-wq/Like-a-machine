# Like a Machine

App pessoal de planejamento do dia e da semana. Este repositório tem só o código do site (GitHub Pages).
Nenhum dado pessoal fica aqui: o app lê os dados de um repositório privado com um token de leitura salvo no próprio aparelho.

## Estilo

Não usar a fonte Instrument Serif (serifada em itálico). Textos usam Archivo, Instrument Sans e IBM Plex Mono.
